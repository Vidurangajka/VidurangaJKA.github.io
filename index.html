About Me

I'm a hardware engineer with a passion for building systems that sit at the intersection of materials science, electromagnetics, and human interfaces. My work spans from finite element simulation to hands-on fabrication — I like knowing how something works all the way down.

At NUS, I've been developing magnetic e-skin sensors — stretchable composite materials embedded with NdFeB powder that can detect pressure and deformation using Hall-effect sensor arrays. It's the kind of problem that requires you to think in magnetic fields, silicone chemistry, and PCB layout all at once.

Outside the lab, I design parametric CAD models in Fusion 360 and prototype with 3D printing — always iterating, always asking whether the design can be cleverer. I believe the best engineering work is both precise and a little bit beautiful.

Projects

P-001

Magnetic E-Skin Sensor Array

Stretchable pressure sensor using NdFeB-embedded Ecoflex silicone and a Hall-effect sensor array. Detects sub-Newton normal and shear forces across a 4×4 sensing grid with <5% hysteresis.

Ecoflex Composites NdFeB Powder Hall Sensors FEMM Simulation

P-002

Halbach Array Field Optimizer

FEMM-based parametric simulation of Halbach array geometries for maximising flux density on the sensing face. Automated parameter sweeps across magnet thickness, pitch, and array segmentation.

FEMM 4.2 Lua Scripting Python Post-Processing Magnetostatics

P-003

Print-in-Place Chainmail Mesh

Parametric Fusion 360 design for a compliant, print-in-place square tile chainmail structure. Designed for wearable applications — tunable link clearances, single-print assembly-free fabrication.

Fusion 360 Parametric CAD FDM Printing Section Analysis

P-004

Coil Geometry Modelling for Inductive Sensing

Electromagnetic coil geometry study using finite element methods to characterise inductance sensitivity to deformation in flexible substrates. Informed coil winding specs for embedded sensing applications.

FEM Inductive Sensing FEMM Coil Design

P-005

Sensor Characterisation Rig

Custom test setup for systematic characterisation of e-skin sensor response — force-displacement curves, drift measurement, and spatial sensitivity mapping using controlled indentation apparatus.

Data Acquisition Python Matplotlib Arduino

P-006

Ecoflex Composite Fabrication Process

Development and optimisation of a reproducible moulding process for NdFeB-Ecoflex composites — controlling powder concentration, mixing protocols, curing cycles, and post-magnetisation alignment.

Silicone Fabrication Material Characterisation Magnetic Alignment
