About Me

I'm a third-year Electronics and Telecommunication Engineering undergraduate at the University of Moratuwa, Sri Lanka, with a GPA of 3.7/4.0 (91.75/100). My work spans the full hardware stack — from transistor-level analog circuit design to FPGA architecture and embedded firmware.

Currently at the National University of Singapore, I'm developing real-time MagLev control systems and high-current H-bridge drive stages for electromagnetic actuation — work that demands precision across analog design, sensor integration, and control theory simultaneously.

Beyond the lab, I freelance as a PCB designer on Fiverr, serve as R&D Director at OREPA, and volunteer as a Mathematics instructor. I believe engineering is most powerful when it's accessible — whether designing a smart greenhouse for Sri Lankan farmers or a concert wristband that syncs thousands of LEDs in real time.

Projects

P-001 · NUS Singapore · 2026

MagLev Control System

Real-time magnetic levitation control algorithm maintaining precise stable equilibrium of levitated elements via optimised PWM duty cycles. Engineered high-current H-bridge drive stages with snubber circuits and flyback diodes. Closed-loop Hall-effect feedback with active EMI filtering for high-SNR position tracking.

Control Systems H-Bridge Design Hall Sensors Analog Circuits PWM

P-002 · Ongoing

RISC-V Processor (RV32I) on FPGA

Designed a full RV32I RISC-V processor in Verilog, synthesised on a ZYNQ 7000 FPGA at 50 MHz. Supports arithmetic and control instructions with complete verification in ModelSim. Git-based collaborative development.

Verilog ZYNQ 7000 Vivado ModelSim Processor Architecture

P-003 · IIT Kanpur · 2025

QPSK Transceiver (HDL)

Optimised a QPSK transceiver for hardware generation using HDL Coder and DSP HDL Toolbox with fixed-point compatibility. Implemented Digital AGC, symbol timing synchronisation, carrier phase/frequency recovery, and 13-bit Barker preambles.

HDL Coder DSP HDL Toolbox MATLAB Signal Processing Fixed-Point

P-004 · Robotic Gen · 2024–Present

ESP32-S3 Custom Development Board

Led design of a compact 4-layer ESP32-S3 IoT development board (48.13×25.27 mm) featuring USB-C, Wi-Fi/Bluetooth, GPIO breakouts, LED indicators, and a robust power distribution network with onboard antenna optimised for IoT applications.

EasyEDA ESP32-S3 4-Layer PCB USB-C RF Design

P-005 · Ongoing

12-Layer PCB for NXP i.MX6

Designing a 12-layer PCB for the NXP i.MX6 1.2 GHz processor in Altium Designer, with advanced stackup management for signal integrity and power distribution across DDR3 and high-speed USB interfaces.

Altium Designer NXP i.MX6 DDR3 Signal Integrity 12-Layer PCB

P-006 · 2024–Present

Smart Communication Wristband

ESP32-based wristband for synchronised LED displays at concerts via MQTT. Integrated ML for music genre detection and Spotify API for playlist syncing. Features voice control and a React web/mobile interface for real-time group synchronisation.

ESP32 MQTT React Machine Learning Spotify API

P-007 · UoM EN2160 · 2025

Restaurant Service Robot

Embedded firmware on SAM3X8E for an autonomous restaurant robot — line-following, S-curve motion profiling, obstacle detection. Managed proximity/ultrasonic sensor integration, PCB design, and Git repository for a 10-member team.

C · SAM3X8E Atmel Studio PCB Design RS-485/232 Motion Control

P-008 · 2024–Present

Smart IoT Greenhouse System

ESP32-based autonomous greenhouse for Sri Lankan farmers — monitoring temperature, humidity, soil moisture, light, and pH. Automated irrigation via solenoid valves and predictive algorithms, backed by MQTT/HTTP, MySQL, and a React real-time dashboard.

ESP32 MQTT/HTTP React Node.js MySQL

P-009 · 2023–2024

CAN-Based Battery Management System (EV)

CAN-based battery swapping station for electric vehicles using AVR microcontrollers. Implemented firmware for central, initial, and end nodes with CAN and Pylon protocols. Extensive testing validated system reliability for sustainable EV applications.

AVR CAN Protocol Pylon Protocol BMS
